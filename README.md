# AIツール比較メモ

ブラウザだけで動作する、AIツールの月額料金・用途メモを一覧管理・比較できるWebアプリケーションです。  
外部ライブラリやビルド環境を必要とせず、HTML・CSS・JavaScript（Vanilla JS）のみで動作します。

---

## 1. ファイル構成

- `index.html` : 画面構造（入力フォーム、検索・ソート操作欄、一覧テーブル）
- `style.css` : スタイル定義（PC向けテーブル表示およびスマートフォン向けカード型レスポンシブレイアウト）
- `app.js` : アプリケーションロジック（CRUD、検索、ソート、`localStorage` 永続化、入力検証、XSS対策、CSV出力）
- `README.md` : 本ドキュメント（動作確認方法・AIを使用した箇所と検証内容）

---

## 2. 動作確認方法

### 起動手順
1. リポジトリのファイルをダウンロード（または `git clone`）します。
2. `index.html` をそのままWebブラウザ（Google Chrome / Safari / Edge / Firefox 等）で開いてください（サーバーの立ち上げは不要です）。

### 各機能の確認手順

| 確認項目 | 確認手順・期待される動作 |
| :--- | :--- |
| **1. 初期データの表示** | 初回起動時に `Alpha`（¥3,000 / 文章）、`Beta`（¥0 / 調査）、`Gamma`（¥5,000 / 画像）の3件が表示されます。 |
| **2. 追加・編集・削除** | ・上部フォームにツール名・月額料金・メモを入力し「＋ 追加する」を押すと一覧に追加されます。<br>・各行の「編集」ボタンを押すとフォームが編集モードに切り替わり、内容を更新できます。<br>・「削除」ボタンを押すと確認ダイアログ後に削除されます。 |
| **3. 部分一致検索** | 検索欄にキーワード（例：`調査` や `al` など）を入力すると、ツール名・メモのどちらかに部分一致する行がリアルタイムで絞り込まれます。 |
| **4. 料金の昇順・降順並べ替え** | 「並べ替え」セレクトボックス（またはテーブル見出しの「月額料金 ↕」ボタン）から、登録順 / 料金の昇順（安い順） / 料金の降順（高い順）を切り替えられます。 |
| **5. localStorage保存・初期状態リセット** | ・追加・編集・削除を行った後、ブラウザを再読み込み（F5）してもデータが保持されます。<br>・画面右上の「↺ 初期状態へリセット」ボタンを押すと、初期データ（3件）の状態に戻ります。 |
| **6. CSVダウンロード（日本語対応）** | 画面右上の「📥 CSVダウンロード」ボタンを押すと、現在表示中の一覧データがUTF-8（BOM付き）のCSVファイルとして保存され、Excel等で開いても日本語が文字化けしません。 |
| **7. 入力検証（空欄・0円・重複）** | ・**空欄検証**：いずれかの項目が空欄（またはスペースのみ）の場合、エラーメッセージを表示して登録を防止します。<br>・**0円許容**：月額料金に `0` を入力した場合は無料ツールとして正常に登録できます（マイナス値や小数はエラーになります）。<br>・**重複検証**：既存のツール名と同名（大文字・小文字を区別しない）のツールを追加・変更しようとするとエラーを表示します（編集時に自分自身の元の名前は維持可能）。 |
| **8. XSS対策（安全な表示）** | ツール名やメモに `<script>alert(1)</script>` や `<img src=x onerror=alert(1)>` などを入力しても、HTMLとして解釈・実行されず、安全なテキストとしてそのまま表示されます。 |
| **9. スマートフォン対応** | ブラウザの開発者ツール等で画面幅を `640px` 以下（スマートフォンサイズ）に縮小すると、横スクロール不要のカード型レイアウトに自動で切り替わります。 |

## 3. AIを使った箇所と人間による確認・修正工程

### AIを使用した箇所
- **ベースコードの生成**：HTMLのセマンティックな構造、CSSのレスポンシブデザイン（PCでのテーブル表示からスマホでのカード表示への切り替え）、JavaScriptによるCRUD・検索・ソート処理の初期実装にAI（Gemini）を活用しました。
- **エッジケースの洗い出し**：入力バリデーションやCSV出力時のエスケープ仕様の整理に活用しました。

### AIの出力から人間が確認・修正した箇所（品質担保の工程）
1. **空欄入力と「0円」の厳密な区別（入力検証の改善）**
   - **修正前の課題**：JavaScriptでは `Number("")` が `0` と評価されるため、数値変換後に `>= 0` で判定すると「料金欄が空欄のままでも0円として通過してしまう」または逆に「`!monthly` で判定すると0円が弾かれてしまう」問題が起きやすい。
   - **修正内容**：入力文字列の `.trim() === ""` を先にチェックして空欄エラーとし、その上で正規表現 `/^\d+$/` と `Number.isSafeInteger()` で「0以上の整数」を検証するように実装しました。これにより空欄は確実に弾き、`0`（0円）は正常に登録できるようになりました。
2. **編集時の名前重複判定と表記ゆれへの対応**
   - **修正前の課題**：単純な名前一致だけで重複判定を行うと、既存データを編集して料金やメモだけを変更したい場合に「自分自身の名前」と重複判定されて更新できなくなるほか、前後スペースや大文字・小文字の違い（`Alpha` と `alpha`）がすり抜ける問題がありました。
   - **修正内容**：重複チェック時に `item.id !== currentEditingId` で編集中の自分自身を除外し、`.trim().toLowerCase()` で正規化した上で比較するように修正しました。
3. **CSV出力時の日本語文字化け防止・エスケープ処理**
   - **修正前の課題**：通常のUTF-8文字列だけでCSVを生成すると、Windows版Excel等で開いた際に「文章」「調査」「画像」などの日本語が文字化けするほか、メモ内にカンマ `,` やダブルクォーテーション `"` が含まれると列ズレが発生します。
   - **修正内容**：先頭にUTF-8 BOM（`\uFEFF`）を付与し、各セルの値をRFC 4180準拠でエスケープ処理するとともに、先頭が `=`, `+`, `-`, `@` で始まる場合のCSVインジェクション対策も追加しました。
4. **XSS対策の徹底（`innerHTML` の排除）**
   - **確認・修正内容**：一覧テーブルやエラーメッセージの描画において、テンプレートリテラルと `innerHTML` を使う実装を避け、すべて `document.createElement()` と `textContent` のみでDOMを構築するように統一し、HTMLタグを入力してもスクリプトが一切実行されないことを確認しました。
